# Changelog

## 1.0.0 - 2026-09-19

First public release of Agent Native.

- Added deterministic checks for agent discoverability, documentation quality, API readiness, and public credential exposure.
- Added passive target policy and SSRF boundary controls.
- Added canonical detection for raw, bearer, percent-encoded, and double-encoded credential forms.
- Added a safe public report boundary for terminal, JSON, and Markdown output.
- Added independent QA evidence, security regression coverage, mutation checks, packaging validation, and release documentation.
- Added Apache 2.0 licensing, contribution guidance, security reporting guidance, and project governance files.
